# План развития: от базового сервиса к инструменту астролога-практика

Сравнение текущего приложения с чек-листом профессионального софта (уровня ZET, Solar Fire, Sirius),
задачи с приоритетами, способ реализации и стоимость.

Обозначения трудоёмкости (оценка на одного разработчика): **S** — до 1 дня, **M** — 2–4 дня,
**L** — неделя и больше.

## 2. Что бесплатно, а что нет

**Главное: все расчёты идут в браузере пользователя**, поэтому почти всё из чек-листа реализуется
**бесплатно** и не нагружает сервер, даже при тысячах пользователей.

| Ресурс | Стоимость | Комментарий |
|---|---|---|
| Swiss Ephemeris (планеты, дома, затмения, сидерика, астероиды) | **Бесплатно** | При открытом коде (AGPL) — наш вариант. Закрыть код = профессиональная лицензия Astrodienst, 700 CHF |
| Хостинг сайта (Cloudflare Workers, статика) | **Бесплатно** | Статические файлы и расчёты в браузере |
| Файлы эфемерид: доп. астероиды, точные эфемериды | **Бесплатно** | Скачиваются у Astrodienst (GitHub / Dropbox), кладутся в `public/ephe`. Растёт только размер сайта |
| Каталог неподвижных звёзд | **Бесплатно** | `sefstars.txt` (AGPL) или открытые каталоги; считаем сами |
| Поиск городов (Open-Meteo) | **Бесплатно, пока сайт некоммерческий** | При монетизации — платный тариф или своя база городов |
| Хранение клиентов / событий в браузере | **Бесплатно** | Только на этом устройстве |
| Синхронизация между устройствами, аккаунты (Supabase и т. п.) | **Бесплатно на старте, потом платно** | Бесплатный тариф с лимитами; при росте — платный план (у Supabase Pro порядка $25/мес) |
| Свой домен вместо `*.workers.dev` | **Платно**, около $10–15 в год | Необязательно |

Платное появляется только в трёх случаях: монетизация (геокодинг), облачное хранение данных
пользователей при росте и собственный домен.

## 3. Задачи по приоритетам

### P0 — без этого нет профессионального прогноза

#### P0-1. Общий движок «методов прогноза» — **M**, бесплатно
Сейчас внешнее кольцо умеет только транзиты. Нужно обобщить его до «метода»: транзиты,
прогрессии, дирекции, соляр — каждый со своими точками, орбисами и фильтрами.
- Режим в шапке: Натал / Транзиты / Прогрессии / Дирекции / Соляр (/ Лунар).
- Для каждого метода — свой пресет орбисов (сейчас есть `aspects` и `transitOrbPreset`; сделать
  словарь пресетов по методам) и свой набор «Аспекты к».
- Таблицы, фигуры, «Динамика» работают для любого метода.
- **Основа для всех задач ниже**, делать первой.

#### P0-2. Вторичные прогрессии (1 день = 1 год) — **S**, бесплатно
- Позиции на момент: рождение + (возраст в годах) суток. Это обычный расчёт планет на другую дату.
- Прогрессивные ASC/MC (метод по солнечной дуге в MC — стандартный вариант, Naibod — опция).
- Прогрессивная Луна (~1° в месяц): отдельная строка со скоростью и датой входа в следующий знак.
- Фаза прогрессивной лунации (новолуние / полнолуние): угол прогрессивных Солнца и Луны.
- Орбис по умолчанию 1°.

#### P0-3. Дирекции: солнечной дуги, символические 1°/год, конверсные — **S–M**, бесплатно
- Солнечная дуга = прогрессивное Солнце − натальное Солнце; прибавляется ко всем точкам карты.
- Символические: дуга = возраст × 1° (опционально Naibod 0°59′08″).
- Переключатель «Директные / Конверсные»: дуга со знаком минус.
- Аспекты дирекционных точек к натальным, орбис 1°.

#### P0-4. Соляр и лунар с релокацией — **M**, бесплатно
- Поиск точного момента возврата Солнца (Луны) в натальный градус: итерации (метод Ньютона) по
  `calculatePosition` — в нашей библиотеке нет готовой функции, но это ~30 строк кода.
- Место соляра: «место рождения» / «текущее место» / любой город (используем готовое окно выбора
  места из транзитов). Дома и углы считаются для выбранного места.
- Показ: отдельная карта соляра и двойной круг «натал + соляр».
- Список: соляры на ±5 лет, лунары на год вперёд.

#### P0-5. Орбисы по методам — **S**, бесплатно (идёт вместе с P0-1)
- Таблицы орбисов для транзитов, прогрессий, дирекций, соляров; формула пары; порог расходящихся.
- Значения по умолчанию: транзиты 1° (Солнце 1.5°), прогрессии и дирекции 1°, соляр — как натал
  или уже.

### P1 — скорость и удобство на консультации

#### P1-1. Тройной круг: натал + прогрессии/дирекции + транзиты — **M**, бесплатно
- Три кольца в `ChartWheel`: пересчитать радиусы колец и раздвижку символов.
- Аспекты: выбор, какие пары показывать (внешнее → натал, среднее → натал).

#### P1-2. Временной слайдер — **S**, бесплатно
- Ползунок в «Динамике» (± N лет/месяцев/дней от выбранной даты) в дополнение к кнопкам шага.
- Без автоматической анимации (анимацию сознательно убрали).
- Работает для любого метода из P0-1.

#### P1-3. Индикатор входа / выхода из орба — **S**, бесплатно
- В таблице аспектов и в «Динамике»: «входит в орб через 3 дня», «точный через 12 дней»,
  «выходит через …». Считается поиском по времени (см. P2-2).

#### P1-4. Фильтр быстрых планет по методам — **S**, бесплатно
- Флажки «Луна / Меркурий / Венера / Солнце / Марс» для каждого метода.
- Пресет «Только медленные (Юпитер–Плутон)» для долгосрочных транзитов.

#### P1-5. Топоцентрические дома — **S**, бесплатно
- Библиотека поддерживает (Polich-Page, код `T`), добавить в список систем домов.
- Заодно можно открыть Alcabitus, Morinus, Meridian, Vehlow — тоже поддерживаются.

#### P1-6. Узлы и Лилит: True / Mean — **S**, бесплатно
- Переключатели «Узел: истинный / средний», «Лилит: средняя / истинная» вместо отдельного
  доп. объекта.
- Показ южного узла (северный + 180°).

### P2 — глубокая аналитика и планирование

#### P2-1. Календарь / график аспектов на период (диаграмма Ганта) — **M–L**, бесплатно
- Для выбранного периода (месяц, год): полосы «вход в орб → точный → выход» для каждого аспекта
  транзита / прогрессии / дирекции к наталу.
- Расчёт: позиции с шагом (день для медленных, час для Луны) + уточнение точной даты бисекцией.
  Это тысячи расчётов, но в браузере это доли секунды; тяжёлые случаи — в Web Worker.

#### P2-2. Поиск точных касаний — **M**, бесплатно
- «Когда транзитный Сатурн сделает квадрат к натальному Солнцу», «когда дирекционный ASC
  войдёт в соединение с …», «вход планеты в дом».
- Тот же механизм, что в P2-1; результат — список дат.

#### P2-3. Затмения на натальной карте — **S–M**, бесплатно
- Библиотека умеет искать солнечные и лунные затмения (`findNextSolarEclipse`,
  `findNextLunarEclipse`).
- Список ближайших затмений (±2 года) с градусом, домом и аспектами к натальным точкам.
- Отметка затмения на круге.

#### P2-4. Ингрессии в знаки и дома — **S–M**, бесплатно
- Календарь переходов планет в знаки и в натальные дома, ретроградность и стоянки.
- Механизм поиска из P2-2.

#### P2-5. Арабские жребии — **S**, бесплатно
- Парс Фортуны (дневная / ночная формула), Духа, Брака и др. — простые формулы от ASC и планет.
- Как доп. объекты: вкладка «Доп. объекты», таблицы, круг.

#### P2-6. Сидерический зодиак — **M**, бесплатно
- Библиотека поддерживает айанамши (Лахири, Фаган–Брэдли, Раман и др.).
- Планеты — флагом расчёта; куспиды — вычитанием айанамши (функция домов в обёртке без флагов).
- Переключатель Tropical / Sidereal + выбор айанамши в «Параметрах».

#### P2-7. Сохранение клиентов и событий — **M**, бесплатно (в браузере)
- Список карт (клиенты, близкие) и список событий клиента — нужно для ректификации (P3-1).
- Хранение в браузере; экспорт / импорт файла для переноса между устройствами.
- Облачная синхронизация — отдельно, см. P3-4.

### P3 — профессиональное конкурентное преимущество

#### P3-1. Модуль ректификации — **L**, бесплатно
- Ввод событий клиента (свадьба, переезд, роды, операции) с датами (P2-7).
- Перебор времени рождения в заданном окне (например, ±2 часа с шагом 1–2 минуты) и оценка
  точности аспектов дирекций / транзитов к ASC/MC на даты событий.
- Результат — список лучших вариантов времени с «весом». Считается в Web Worker.
- Требует P0-3 (дирекции) и P2-2 (поиск касаний).

#### P3-2. Неподвижные звёзды — **M**, бесплатно
- В нашей обёртке нет функции звёзд: берём каталог (`sefstars.txt` или открытый) и считаем
  положение с прецессией сами.
- 20–30 ключевых звёзд (Алголь, Регул, Сириус, Альдебаран, Спика, Антарес…), соединения
  с орбисом 1° к планетам и углам.

#### P3-3. Расширенная база астероидов — **M**, бесплатно
- Файлы отдельных астероидов (Эрос, Психея, Эрида, Лилит-астероид и т. д.) есть у Astrodienst
  (GitHub / Dropbox), без прямых ссылок для браузера.
- Скачать нужные вручную, положить в `public/ephe`, добавить в каталог «Доп. объектов».
- Каждый файл увеличивает размер сайта; грузить только при включении объекта.

#### P3-4. Аккаунты и синхронизация — **L**, бесплатно на старте, потом платно
- Вход, хранение карт и настроек в облаке (Supabase / Firebase).
- Бесплатный тариф с лимитами; при росте — платный план.
- Потребуются политика конфиденциальности и защита персональных данных (даты рождения).

## 4. Рекомендуемый порядок

1. **P0-1 + P0-5** — движок методов и орбисы по методам (фундамент).
2. **P0-2** прогрессии → **P0-3** дирекции → **P0-4** соляр/лунар.
3. **P1-5, P1-6, P1-4, P1-2** — быстрые улучшения (каждое до дня).
4. **P1-1** тройной круг, **P1-3** индикатор орба.
5. **P2-2** поиск касаний → **P2-1** календарь → **P2-3** затмения → **P2-4** ингрессии.
6. **P2-5** жребии, **P2-6** сидерика, **P2-7** клиенты.
7. **P3-1** ректификация, затем **P3-2**, **P3-3**, **P3-4** по запросам пользователей.

Весь блок P0–P2 реализуется без затрат: только код, расчёты в браузере, бесплатный хостинг.
